Rule language
allow / drop
What to do with a packet that matches. Every condition after it must match.
policy drop
What happens to packets that no rule matched. Starts as allow.
tcp · udp · icmp
Protocol.
port 22
Destination port: 22, 80,443 or 1024-65535. Needs tcp or udp.
sport 53
Source port. The sender chooses it freely.
from 10.0.0.0/8
Source address or network.
in wan · in lan
Interface the packet arrived on: wan is the internet, lan the internal network.
state established
Reply to a connection the server opened itself. state new is everything else.
limit 3/m per-src
Match at most 3 packets a minute (/s per second), counted per source address. Extra packets skip this rule and go on to the next one.
